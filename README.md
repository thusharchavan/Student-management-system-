# Student Management System

A simple and efficient Student Management System designed to manage and organize student records seamlessly.

## 🚀 Features
* **Add Student:** Easily register new students into the system.
* **View Records:** Display a comprehensive list of all enrolled students.
* **Update & Delete:** Modify existing details or remove student profiles.
